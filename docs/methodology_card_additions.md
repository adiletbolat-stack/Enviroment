## 2. Блок «Тип исследования» и его обоснование

**Тип исследования:** Смешанный дизайн (Mixed-Methods Design: качественный контент-анализ + непараметрический количественный анализ наблюдационных данных).

### Обоснование выбора дизайна:
1. **Качественная составляющая:**
   - Исследование базируется на текстах естественных пользовательских отчётов в тематических онлайн-сообществах (Reddit: r/replika, r/CharacterAI).
   - Разработана структурированная кодовая книга (Codebook v1.0), фиксирующая качественные категории: проявления эмоциональной привязанности (`attachment`), страха утраты связи (`fear_of_loss`), инструментально-эмоциональной поддержки (`daily_support`) и паттернов избегания контактов с реальными людьми (`social_avoidance`).
   - Оценка надежности кодирования проводится через двойное независимое кодирование случайной подвыборки (15–20% корпуса) с расчетом каппы Коэна ($\kappa \ge 0.60$).
2. **Количественная составляющая:**
   - Для устранения артефактов разной длины сообщений частоты маркеров нормализуются на 1 000 слов ($F_i$, $I_i$).
   - Для предотвращения псевдорепликации (pseudoreplication) единицей наблюдения и агрегации является уникальный автор.
   - Проверка статистических гипотез проводится строгими непараметрическими тестами:
     - Односторонний $U$-критерий Манна–Уитни и дельта Клиффа ($\delta$) с 95% bootstrap-доверительными интервалами (RQ2: группы `<1 мес.` vs `>3 мес.`);
     - Критерий Краскела–Уоллиса и критерий упорядоченных альтернатив Йонкхиера–Терпстра (монотонный рост частоты по трём группам длительности);
     - Ранговая корреляция Спирмена ($\rho$) и контролируемая OLS-регрессия (RQ3: связь длительности/интенсивности с индексом изоляции–избегания).

## 3. Устранение двойственности в гипотезе RQ3 (Одна независимая переменная)

### Проблема исходной редакции:
Формулировка «длительность/интенсивность» объединяла два разнородных фактора в одной статистической гипотезе, что нарушало однозначность тестирования $H_0$.

### Скорректированная формулировка:
- **Основная исследовательская гипотеза (RQ3):**
  - **Главная независимая переменная (IV):** Длительность использования ИИ-компаньона в месяцах (`duration_months`).
  - **Зависимая переменная (DV):** Индекс изоляции–избегания $I_i$ (количество маркеров социального избегания на 1 000 слов).
  - **Нулевая гипотеза ($H_0$):** Монотонная связь между длительностью использования и индексом изоляции–избегания отсутствует ($\rho_s \le 0$).
  - **Альтернативная гипотеза ($H_1$):** Длительность использования положительно коррелирует с индексом изоляции–избегания ($\rho_s > 0$).
- **Статус переменной интенсивности (`sessions_per_week`):**
  - Интенсивность (количество сессий в неделю) переводится в статус **контрольной ковариаты**.
  - Дополнительно оценивается множественная линейная регрессионная модель:  
    $$I_i = \beta_0 + \beta_1 \cdot \text{duration\_months}_i + \beta_2 \cdot \text{sessions\_per\_week}_i + \varepsilon_i$$  
    для изолированной оценки вклада длительности при фиксации недельной активности пользователя.

## 4. Оценка и обоснование размера выборки (Power Analysis)

1. **Анализ мощности для RQ2 (Критерий Манна–Уитни, 2 группы):**
   - Параметры: $\alpha = 0.05$ (односторонний критерий), мощность $1 - \beta = 0.80$.
   - Ожидаемый минимальный размер эффекта: средний эффект по шкале дельты Клиффа $\delta \ge 0.33$ (эквивалентно $d \approx 0.50$ Коэна).
   - Необходимый размер подвыборки: не менее **$n_1 = n_2 = 53$ авторов** в каждой экстремальной группе (`<1 месяца` и `>3 месяцев`), суммарно для контраста $N_{\text{contrast}} \ge 106$ авторов.
2. **Анализ мощности для вторичного тренда (Йонкхиер–Терпстра, 3 группы):**
   - При трёх упорядоченных группах (`<1 мес.`, `1–3 мес.`, `>3 мес.`) и среднем стандартизованном тренде достаточная мощность $0.80$ достигается при общем объеме выборки **$N \ge 120$ авторов** (~$40$ авторов на группу).
3. **Анализ мощности для RQ3 (Ранговая корреляция Спирмена):**
   - Для выявления умеренной корреляции ($\rho \ge 0.25$) при $\alpha = 0.05$ (односторонний) и $1 - \beta = 0.80$ необходим объем выборки **$N \ge 99$ авторов**.
4. **Поправка на фильтрацию и отсев сырых данных:**
   - Эмпирический уровень отсева текстов короче порога содержательности ($w < 100$ слов) составляет около 40–45%.
   - Уровень исключения записей с неподтвержденным статусом студента (`student_evidence = unknown`) составляет около 15–20%.
   - **Итоговая рекомендация по сбору первичных данных:** сырой корпус текстов должен включать не менее **350–400 сообщений** (уникальных авторов), что гарантированно обеспечивает не менее **150–170 авторов** в финальном чистом датасете (`analysis_set.csv`).
